# TripPilot Frontend Development Guide

This guide provides comprehensive instructions for developers working on the TripPilot travel CRM frontend. Follow these patterns and conventions to maintain consistency with the enterprise design system.

---

## 🎯 Quick Start

### Creating a New Page

All pages should follow this structure:

```tsx
"use client";

import { PageHeader, PageContainer } from "@/components/layout";
import { Card, CardContent, CardHeader, CardTitle } from "@/components/ui/card";
import { Button } from "@/components/ui/button";
import { Input } from "@/components/ui/input";

export default function NewPage() {
  return (
    <PageContainer>
      <div className="space-y-6">
        <PageHeader 
          title="Page Title" 
          description="Brief description of the page"
        />
        
        {/* Your content here */}
        <Card>
          <CardHeader>
            <CardTitle>Section Title</CardTitle>
          </CardHeader>
          <CardContent className="space-y-4">
            {/* Content */}
          </CardContent>
        </Card>
      </div>
    </PageContainer>
  );
}
```

### Creating a New Component

All UI components should:
1. Export a named component (not default)
2. Accept a `className` prop for customization
3. Use TypeScript interfaces for props
4. Be located in `components/ui/` for reusable components

```tsx
import { cn } from "@/lib/cn";

export interface CustomComponentProps {
  label: string;
  disabled?: boolean;
  className?: string;
}

export function CustomComponent({
  label,
  disabled = false,
  className,
}: CustomComponentProps) {
  return (
    <div className={cn("space-y-2", className)}>
      <label className="font-semibold text-sm">{label}</label>
      {/* Component content */}
    </div>
  );
}
```

## 🎨 Design System

### Colors (Use CSS Variables)

All colors are defined as CSS variables in `globals.css`. Use them via Tailwind:

```tsx
// Primary color
<div className="bg-primary text-primary">Primary</div>

// Semantic colors
<div className="bg-destructive text-destructive-foreground">Error</div>
<div className="bg-success text-success-foreground">Success</div>
<div className="bg-warning text-warning-foreground">Warning</div>

// Backgrounds
<div className="bg-background text-foreground">Main background</div>
<div className="bg-muted text-muted-foreground">Secondary background</div>
```

### Spacing Scale

Use Tailwind spacing utilities (4px base):

```tsx
// Margin
<div className="m-1">4px</div>
<div className="m-2">8px</div>
<div className="m-4">16px</div>
<div className="m-6">24px</div>

// Padding
<div className="p-4">Padding 16px</div>

// Gap (flex/grid)
<div className="flex gap-4">Items with 16px gap</div>
```

### Typography

Use semantic classes:

```tsx
// Headings
<h1 className="text-3xl font-bold">Display (32px, bold)</h1>
<h2 className="text-2xl font-bold">Heading 1 (24px, bold)</h2>
<h3 className="text-lg font-semibold">Heading 2 (18px, semibold)</h3>
<h4 className="text-base font-semibold">Heading 3 (16px, semibold)</h4>

// Body text
<p className="text-base">Body (16px)</p>
<p className="text-sm">Label (14px)</p>
<p className="text-xs">Caption (12px)</p>
<code className="text-sm font-mono">Code (14px, monospace)</code>
```

### Responsive Design

Mobile-first Tailwind breakpoints:

```tsx
<div className="
  grid 
  grid-cols-1              // Mobile: 1 column
  sm:grid-cols-2           // 640px+: 2 columns
  lg:grid-cols-3           // 1024px+: 3 columns
  gap-4
">
  {/* Items */}
</div>

// Responsive text
<p className="text-sm md:text-base lg:text-lg">Text</p>

// Conditional visibility
<div className="hidden md:block">Visible on tablet+</div>
<div className="md:hidden">Visible on mobile only</div>
```

## 📦 Core Components

### Layout Components (`components/layout/`)

**PageContainer** — Provides consistent max-width and padding
```tsx
<PageContainer>
  <PageHeader title="Title" description="Description" />
  {/* Content */}
</PageContainer>
```

**PageHeader** — Title + optional description + action slot
```tsx
<PageHeader 
  title="Leads"
  description="Manage customer leads"
/>
```

**Section** — Grouped content with optional title
```tsx
<Section title="Profile Details" description="Update your information">
  <Input placeholder="Name" />
</Section>
```

**ResponsiveGrid** — Adaptive grid layout
```tsx
<ResponsiveGrid columns={3} gap="md">
  <Card>Item 1</Card>
  <Card>Item 2</Card>
  <Card>Item 3</Card>
</ResponsiveGrid>
```

### UI Components (`components/ui/`)

**Button** — Primary, secondary, destructive, outline, ghost, link
```tsx
<Button variant="primary">Primary</Button>
<Button variant="outline">Outline</Button>
<Button variant="destructive">Delete</Button>
<Button size="sm">Small</Button>
<Button disabled>Disabled</Button>
```

**Input** — Text input with optional label and error
```tsx
<div className="space-y-2">
  <Label htmlFor="email">Email</Label>
  <Input 
    id="email"
    type="email"
    placeholder="user@example.com"
  />
</div>
```

**Card** — Container with header/footer sections
```tsx
<Card>
  <CardHeader>
    <CardTitle>Title</CardTitle>
    <CardDescription>Description</CardDescription>
  </CardHeader>
  <CardContent className="space-y-4">
    {/* Content */}
  </CardContent>
  <CardFooter>
    <Button>Action</Button>
  </CardFooter>
</Card>
```

**Badge** — Status indicators
```tsx
<Badge variant="primary">Active</Badge>
<Badge variant="success">Completed</Badge>
<Badge variant="warning">Pending</Badge>
<Badge variant="destructive">Error</Badge>
```

**Alert** — Error, warning, success, info messages
```tsx
<Alert variant="destructive">
  <AlertDescription>Error message</AlertDescription>
</Alert>
```

**Dialog** — Modal dialogs
```tsx
<Dialog open={isOpen} onOpenChange={setIsOpen}>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Confirm Action</DialogTitle>
    </DialogHeader>
    <DialogDescription>
      Are you sure?
    </DialogDescription>
  </DialogContent>
</Dialog>
```

## 🏗️ Architecture Patterns

### Page Structure

Every page should follow this pattern:

```tsx
"use client";

import { useState, useEffect } from "react";
import { PageHeader, PageContainer } from "@/components/layout";
import { Card, CardContent } from "@/components/ui/card";
import { Button } from "@/components/ui/button";

export default function PageName() {
  const [data, setData] = useState<any[]>([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    loadData();
  }, []);

  async function loadData() {
    try {
      // Fetch data from API
      const response = await fetch("/api/endpoint");
      setData(await response.json());
    } catch (error) {
      console.error(error);
    } finally {
      setLoading(false);
    }
  }

  return (
    <PageContainer>
      <div className="space-y-6">
        <PageHeader title="Title" description="Description" />
        
        <Card>
          <CardContent className="pt-6">
            {/* Content */}
          </CardContent>
        </Card>
      </div>
    </PageContainer>
  );
}
```

### Form Patterns

Use `FormProvider` + `FormField` for complex forms with validation:

```tsx
import { useForm } from "react-hook-form";
import { zodResolver } from "@hookform/resolvers/zod";
import { z } from "zod";
import { FormProvider, FormField } from "@/components/forms";
import { Button } from "@/components/ui/button";

const schema = z.object({
  name: z.string().min(1, "Name required"),
  email: z.string().email(),
});

type FormData = z.infer<typeof schema>;

export function MyForm() {
  const form = useForm<FormData>({
    resolver: zodResolver(schema),
  });

  async function onSubmit(data: FormData) {
    // Handle submission
  }

  return (
    <FormProvider {...form} onSubmit={onSubmit}>
      <FormField
        control={form.control}
        name="name"
        label="Full Name"
        render={({ field }) => <input {...field} />}
      />
      <FormField
        control={form.control}
        name="email"
        label="Email Address"
        type="email"
        render={({ field }) => <input {...field} />}
      />
      <Button type="submit">Submit</Button>
    </FormProvider>
  );
}
```

### Table Patterns

Use TanStack Table v8 for data tables:

```tsx
import { DataTable } from "@/components/tables/DataTable";
import { ColumnHeader } from "@/components/tables/ColumnHeader";

export function MyTable({ data }) {
  const columns = [
    {
      id: "name",
      header: ({ column }) => <ColumnHeader column={column} title="Name" />,
      cell: ({ row }) => row.original.name,
    },
    {
      id: "email",
      header: "Email",
      cell: ({ row }) => row.original.email,
    },
  ];

  return (
    <DataTable 
      columns={columns} 
      data={data}
      loading={loading}
    />
  );
}
```

### Modal/Drawer Patterns

For side panels or modals, use the drawer pattern:

```tsx
{showDrawer && (
  <div className="fixed inset-0 bg-black/50 z-40 flex items-end" 
       onClick={() => setShowDrawer(false)}>
    <div className="bg-white w-full max-w-2xl h-full overflow-y-auto flex flex-col"
         onClick={(e) => e.stopPropagation()}>
      
      {/* Header */}
      <div className="sticky top-0 bg-white border-b border-border p-6">
        <h3 className="text-lg font-bold">Title</h3>
        <button onClick={() => setShowDrawer(false)}>✕</button>
      </div>

      {/* Content */}
      <form className="flex-1 p-6 overflow-y-auto space-y-6">
        {/* Form fields */}
      </form>

      {/* Footer */}
      <div className="sticky bottom-0 bg-white border-t border-border p-6 flex gap-3 justify-end">
        <Button variant="outline" onClick={() => setShowDrawer(false)}>Cancel</Button>
        <Button variant="primary" type="submit">Save</Button>
      </div>
    </div>
  </div>
)}
```

## 🔧 Common Tasks

### Add a New Page

1. Create file in `app/[page-name]/page.tsx`
2. Use `"use client"` directive
3. Import `PageContainer`, `PageHeader`, and layout components
4. Follow the page structure pattern above
5. Run `npm run build` to verify

### Add a New Component

1. Create file in `components/ui/[component-name].tsx`
2. Export named component with TypeScript props interface
3. Accept optional `className` prop and merge with `cn()`
4. Add JSDoc comment with `@example`
5. Export from `components/ui/index.ts`

### Style a Component

**Never use inline `style={{}}` attributes**

```tsx
// ❌ WRONG
<div style={{ padding: "16px", backgroundColor: "#f3f4f6" }}>

// ✅ CORRECT
<div className="p-4 bg-muted">
```

Always use Tailwind utility classes. If you need custom styles:

```tsx
<div className={cn(
  "p-4 bg-muted rounded-lg",
  "hover:bg-muted/80 transition-colors",
  className
)}>
```

### Use Color Tokens

**Never hardcode hex colors**

```tsx
// ❌ WRONG
<div style={{ color: "#7C3AED" }}>

// ✅ CORRECT
<div className="text-primary">
```

Available semantic colors:
- `primary`, `secondary`, `accent`
- `destructive`, `success`, `warning`, `info`
- `foreground`, `muted-foreground`
- `background`, `muted`, `border`

### Create a Data Table

```tsx
import { useMemo } from "react";
import { createColumnHelper } from "@tanstack/react-table";
import { DataTable } from "@/components/tables/DataTable";
import { ColumnHeader } from "@/components/tables/ColumnHeader";

interface Item {
  id: number;
  name: string;
  status: string;
}

export function ItemsTable({ items, loading }) {
  const columnHelper = createColumnHelper<Item>();

  const columns = useMemo(() => [
    columnHelper.accessor("name", {
      header: ({ column }) => <ColumnHeader column={column} title="Name" />,
    }),
    columnHelper.accessor("status", {
      header: "Status",
      cell: ({ row }) => <Badge>{row.original.status}</Badge>,
    }),
  ], []);

  return <DataTable columns={columns} data={items} loading={loading} />;
}
```

## ✅ Code Standards

### TypeScript

- ✅ Enable strict mode (all files must pass)
- ✅ Use interfaces for component props
- ✅ Import types explicitly: `import type { ComponentProps }`
- ✅ Use `z.infer<typeof schema>` for form data types

### Naming Conventions

- Pages: `PascalCase` (e.g., `DashboardPage`)
- Components: `PascalCase` (e.g., `UserProfile`)
- Functions: `camelCase` (e.g., `getUserData`)
- Files: `kebab-case` (e.g., `user-profile.tsx`)
- CSS classes: `kebab-case` (e.g., `card-header`)

### Imports

```tsx
// Order: React/Next imports, third-party, local
import { useState } from "react";
import { useRouter } from "next/navigation";
import { Button } from "@/components/ui/button";
import { cn } from "@/lib/cn";
```

### Comments

```tsx
// Use single-line comments for inline explanations
const isValid = email.includes("@"); // Basic email validation

// Use block comments for complex logic
/*
 * Validates form data against schema
 * Returns errors object if validation fails
 */
const errors = validateForm(data);
```

## 🐛 Debugging

### Common Issues

**Issue: "Cannot find module '@/components/...'"**
- Check file exists in correct location
- Verify export in component file
- Check `components/ui/index.ts` has export (if UI component)

**Issue: "Property does not exist on type"**
- Import correct component
- Check prop name spelling
- Verify TypeScript types defined in interface

**Issue: Styling not applying**
- Don't use inline `style={{}}` — use Tailwind classes
- Check class names are spelled correctly
- Verify Tailwind is processing the class (run `npm run build`)

**Issue: Build fails with "Failed to type check"**
- Run `npm run build` locally to see full error
- Check all `any` types are documented
- Verify imports are correct

### Debug Commands

```bash
# Full build with type checking
npm run build

# Development build with hot reload
npm run dev

# Check for TypeScript errors only
npm run tsc --noEmit
```

## 🚀 Performance Best Practices

1. **Lazy load heavy components**
   ```tsx
   const HeavyComponent = dynamic(() => import('./HeavyComponent'), {
     loading: () => <Spinner />,
   });
   ```

2. **Memoize expensive calculations**
   ```tsx
   const sortedItems = useMemo(() => items.sort(...), [items]);
   ```

3. **Use `useCallback` for event handlers**
   ```tsx
   const handleClick = useCallback(() => { /* ... */ }, []);
   ```

4. **Avoid rendering in loops**
   ```tsx
   // ❌ WRONG
   {items.map(item => <Component key={item.id} data={getData(item)} />)}
   
   // ✅ CORRECT
   {items.map(item => <Component key={item.id} id={item.id} />)}
   ```

## ♿ Accessibility

All components should be accessible:

1. **Use semantic HTML**
   ```tsx
   // ✅ CORRECT
   <button onClick={handleClick}>Click me</button>
   <a href="/page">Link</a>
   ```

2. **Add labels to inputs**
   ```tsx
   <Label htmlFor="email">Email</Label>
   <Input id="email" type="email" />
   ```

3. **Use ARIA attributes when needed**
   ```tsx
   <div role="alert" aria-live="polite">
     Error message
   </div>
   ```

4. **Ensure keyboard navigation**
   ```tsx
   <button tabIndex={0} onKeyDown={handleKeyDown}>
     Interactive element
   </button>
   ```
